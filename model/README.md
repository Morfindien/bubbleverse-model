# Bubbleverse Formal Model Layer

This directory is the machine-readable formalization of the accepted Bubbleverse model state.

It does **not** add new physics, choose a preferred cosmology, or fill unknown quantities with guesses.
It records parameters, benchmark inference chains, implemented equations, explicit assumptions, uncertainty classes, domains of validity, limitations, schemas, provenance and execution environment.

Current authorized boundary: **Q001-Q039**.
Accepted model: **v0.1**.

Run the public workflow with operation `test` to include the formal-model gate through the normal model validation path.
